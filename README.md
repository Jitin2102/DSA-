## 🧠 My Approach to Every Problem

I try not to jump directly into the optimal code. Instead, I follow a consistent problem-solving process:

1. **Understand:** Identify the input, output, constraints, and edge cases.
2. **Brute Force:** Develop the simplest correct approach.
3. **Optimize:** Look for better algorithms and data structures.
4. **Compare:** Understand the trade-offs between different approaches.
5. **Implement:** Write a clean and efficient C++17 solution.
6. **Analyze:** Evaluate time and space complexity.
7. **Test:** Validate the solution against sample cases and edge cases.

I want to understand not only *what* the optimal solution is, but also *why* it is optimal.

## 💻 Running the Solutions

All solutions are written in C++17.

**1. Clone the repository**

```bash
git clone https://github.com/Jitin2102/DSA-.git
cd DSA-
```

**2. Navigate to a problem**

```bash
cd Day-08
```

**3. Compile**

```bash
g++ -std=c++17 -O2 -Wall A_Custom_Comparator.cpp -o solution
```

**4. Execute**

```bash
./solution
```

On Windows PowerShell:

```powershell
.\solution.exe
```
